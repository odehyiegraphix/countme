two-font system:

Plus Jakarta Sans → primary UI font. Modern, geometric, clean, excellent for dashboards.
DM Mono → numbers, attendance codes, IDs, timestamps, analytics/data elements.

This gives the interface a distinctive identity while keeping it highly readable.

2. The hierarchy I'd use

The important thing is not just having many sizes. The interface should have a very deliberate hierarchy.

For example, an attendance dashboard could look like:

3. A distinctive feature: Data Typography

For an attendance and analytics system, I'd make numbers visually different from normal text.

For example:

┌──────────────────────────────────┐
│ Overall Attendance               │
│                                  │
│ 94.72%                           │
│ +3.42% from last month           │
└──────────────────────────────────┘

The 94.72% uses DM Mono, while everything else uses Plus Jakarta Sans.

This creates a subtle analytics / technology identity without making the entire interface look overly futuristic.

One important rule

I would not go below 14px for normal application body text.

Use 12px–13px only for metadata, badges, table headers, timestamps and other secondary information.

5. Letter-spacing philosophy

I'd keep the typography relatively tight for headings:

Large heading      -1.5px
Medium heading     -1.0px
Small heading      -0.3px
Body               0px
Labels             0px
Data               -0.2px

This is what gives the typography that modern SaaS/dashboard appearance.

Avoid excessive letter spacing such as:

A T T E N D A N C E

unless you're intentionally creating an eyebrow/section label.

For those, you can use:

{
  "eyebrow": {
    "fontFamily": "Plus Jakarta Sans",
    "fontSize": "11px",
    "lineHeight": "16px",
    "fontWeight": 700,
    "letterSpacing": "0.8px",
    "textTransform": "uppercase"
  }
}
